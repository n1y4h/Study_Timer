**My Timer Project**
A simple timer application that I created as one of my programming projects.

**About**
This project was created to practice programming and develop my understanding of how applications work. It was also an opportunity to experiment with building a functional timer.
To use this timer, answer the short quiz at the beginning and let the timer do the rest! Will need to be manually started and can be ended manually as well.

**Features**
> Timer functionality
> User-friendly interface
> Visual display of the countdown

**Technologies Used**
> HTML
> CSS
> JavaScript
> Electron Fiddle

**What I Learned**
> Organizing project files
> Using HTML to structure an application
> Styling an interface with CSS
> Working with JavaScript functionality
> Using Electron Fiddle to create a desktop application
> Uploading and documenting projects with GitHub

**Challenges**
One of the challenges of this project was making sure all the necessary files and image assets were organized correctly so the application would function properly.
